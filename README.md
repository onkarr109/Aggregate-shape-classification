# AI-Based Aggregate Shape Classification

## Project Overview
This project explores the use of Machine Learning to classify coarse aggregate particles based on their shape characteristics.

The project focuses on four aggregate shape categories:

- A – Elongated
- B – Angular
- C – Cubical
- D – Rounded

## Objectives
- Study coarse aggregate shape characteristics.
- Apply Machine Learning algorithms for aggregate shape classification.
- Compare the performance of different classification models.
- Explore AI applications in Civil Engineering.

## Machine Learning Algorithms
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest
5. Support Vector Machine (SVM)

## Dataset and Results
The notebook compares classification models using a small sieve-fraction summary dataset.

Logistic Regression achieved 0.875 accuracy on the 24-row summary dataset using stratified 5-fold cross-validation.

**Note:** This is a feasibility result on the summary dataset. It should not be interpreted as the expected accuracy on individual aggregate particles.
